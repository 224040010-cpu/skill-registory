---
name: sorting-raw-files
description: |
  Scans raw_material/ and copies files by knowledge category into source_file/
  subdirectories (derived_index, evidence, memory_case, etc.), preparing a
  clean per-category layout for downstream preprocessing skills.
  Use when new raw files have been added to raw_material/ and the pipeline
  needs to start from Phase 0, or when a full pipeline re-run is requested.
  Do NOT use when source_file/ is already populated and preprocessing is
  in progress — proceed directly to preprocessing-excel-sources,
  preprocessing-log-sources, or preprocessing-pdf-sources.
---

# Purpose

Organizes raw input files into per-knowledge-category subdirectories under
source_file/ so that each preprocessing skill receives a homogeneous,
category-scoped input set. This is always the first step of the pipeline.

---

# Trigger

**Use this Skill when:**
- New files have been placed in raw_material/ and need to be organized
- A full pipeline run is requested from the beginning (Phase 0)
- source_file/ is empty or needs to be refreshed from raw_material/

**Do NOT use this Skill when:**
- source_file/ subdirectories are already populated — skip to the relevant
  preprocessing skill (preprocessing-excel-sources / preprocessing-log-sources /
  preprocessing-pdf-sources)
- Only specific files need reprocessing — call the preprocessing skill directly

---

# Workflow

[ ] Step 1: 验证输入目录
    - ⚠️ Tool needed: `file-system-mcp:list_files(`path=data_prepare/raw_material/, recursive=true)
    - If 0 files found → return error "raw_material/ is empty, nothing to sort"
    - Log discovered knowledge categories (subdirectory names)

[ ] Step 2: 执行文件分拣
    - ⚠️ Tool needed: `data-pipeline-mcp:run_script(`
        script=scripts/phase0_sort_files.py,
        args=[]
      )
    - Script reads RAW_MATERIAL_DIR and SOURCE_FILE_DIR from its own config
    - If script exits non-zero → return stderr as error message, stop

[ ] Step 3: 验证输出并返回结果
    - ⚠️ Tool needed: `file-system-mcp:list_files(`path=data_prepare/source_file/, recursive=true)
    - Count files per knowledge category subdirectory
    - Return: {categories: [...], total_files: N, by_category: {name: count, ...}, output_dir: "source_file/"}

**Error handling:**
- If raw_material/ does not exist → return "Input directory not found: raw_material/"
- If script fails mid-run → report which category was being processed when failure occurred
- If output file count < input file count → return warning listing uncopied files

---

# Scripts

**phase0_sort_files.py** — Copies files from raw_material/ into source_file/ by knowledge category
- Execute: `python scripts/phase0_sort_files.py`
- Input: RAW_MATERIAL_DIR (hardcoded: data_prepare/raw_material/)
- Output: SOURCE_FILE_DIR (hardcoded: data_prepare/source_file/), per-category subdirs

---

# Constraints

- NEVER delete or modify source files in raw_material/ — this skill only copies
- This skill is READ + WRITE on local filesystem only
- NEVER proceed if Step 1 returns 0 files
- Script uses hardcoded directory paths — do not pass path arguments
- Output must include: categories list, total_files, by_category breakdown, output_dir
