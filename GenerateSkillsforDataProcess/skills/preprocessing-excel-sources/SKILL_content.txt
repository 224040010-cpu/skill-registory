---
name: preprocessing-excel-sources
description: |
  Converts Excel files (.xlsx/.xlsm) from source_file/ into CSV files stored
  in processed_data/table_cache/, making tabular data available for chunking.
  Use when Excel files have been sorted into source_file/ and need to be
  preprocessed before chunking, or when Excel source files have been updated.
  Do NOT use when Excel files have not been sorted yet (run sorting-raw-files
  first), or when only log/PDF sources need processing (use
  preprocessing-log-sources or preprocessing-pdf-sources instead).
---

# Purpose

Reads Excel workbooks from source_file/ and outputs structured CSV files to
processed_data/table_cache/ so that chunking-knowledge-sources can consume
tabular data in a uniform format.

---

# Trigger

**Use this Skill when:**
- source_file/ contains Excel files (.xlsx/.xlsm) ready for preprocessing
- Excel source data has been updated and table_cache/ needs to be refreshed
- Pipeline Phase 1 is running for Excel data type

**Do NOT use this Skill when:**
- source_file/ has not been populated yet (run sorting-raw-files first)
- Only log or PDF data needs preprocessing (use the respective skill)
- table_cache/ is already up to date and no Excel files have changed

---

# Workflow

[ ] Step 1: 检查 Excel 源文件
    - ⚠️ Tool needed: `file-system-mcp:list_files(`path=data_prepare/source_file/, pattern=**/*.xlsx,**/*.xlsm)
    - If 0 Excel files found → return warning "No Excel files found in source_file/, skipping"
    - Log file count

[ ] Step 2: 执行 Excel 预处理
    - ⚠️ Tool needed: `data-pipeline-mcp:run_script(`
        script=scripts/phase1_preprocess_excel_data.py,
        args=[]
      )
    - Script reads from EXCEL_DIR (source_file/) and writes to CSV_OUTPUT_DIR (processed_data/table_cache/)
    - If ModuleNotFoundError: openpyxl → return "Missing dependency: run pip install openpyxl"
    - If script exits non-zero → return stderr as error message, stop

[ ] Step 3: 验证输出
    - ⚠️ Tool needed: `file-system-mcp:list_files(`path=data_prepare/processed_data/table_cache/, pattern=*.csv)
    - If output CSV count < input Excel count → return warning with list of unconverted files
    - Return: {csv_files_created: N, output_dir: "processed_data/table_cache/"}

**Error handling:**
- If openpyxl not installed → return actionable message "pip install openpyxl" before running
- If a specific workbook is corrupt or unreadable → log warning, continue with remaining files
- If table_cache/ directory does not exist → script creates it; if creation fails return OS error

---

# Scripts

**phase1_preprocess_excel_data.py** — Converts Excel workbooks to CSV
- Execute: `python scripts/phase1_preprocess_excel_data.py`
- Input: EXCEL_DIR (hardcoded: data_prepare/source_file/)
- Output: CSV_OUTPUT_DIR (hardcoded: data_prepare/processed_data/table_cache/)
- Requires: `pip install openpyxl`

**common_schema.py** — Shared data schema definitions used by pipeline scripts

---

# Constraints

- NEVER modify or delete source Excel files in source_file/
- This skill is READ (source_file/) + WRITE (processed_data/table_cache/) only
- Requires openpyxl — validate dependency before running in a new environment
- Output must include: csv_files_created count, output_dir
