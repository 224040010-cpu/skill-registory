# runtime/

This directory contains the **Runtime Asset Allowlist** — the contract between
the skill/tool registry and any consuming runtime service (agent, router, etc.).

## `allowlist.json`

Generated by `scripts/runtime_allowlist.py` from `skill-registry.yaml` and
`tool-registry.yaml`.  Only **`approved`** and **`restricted`** assets are
included.

### Key guarantee

> The runtime MUST NOT call any skill or tool that is not present in
> `allowlist.json`.  Checking this file replaces any direct read of the YAML
> registries in production code.

### Schema

```json
{
  "schema_version": "1.0",
  "generated_at": "<ISO-8601 timestamp>",
  "source": { ... registry versions ... },
  "summary": {
    "allowed_skills": 30,
    "allowed_tools":  15,
    "excluded_skills_by_status": { "draft": 0, "deprecated": 0 },
    "excluded_tools_by_status":  {}
  },
  "skills": [ { "name", "version", "status", "risk_level", "bundle_scope", ... } ],
  "tools":  [ { "name", "version", "status", "risk_level", "endpoint", ... } ],
  "excluded": { "skills": {}, "tools": {} }
}
```

### Consumption pattern

```python
import json, pathlib

allowlist = json.loads(pathlib.Path("runtime/allowlist.json").read_text())

# Build callable skill set
APPROVED_SKILLS = {s["name"] for s in allowlist["skills"]}
APPROVED_TOOLS  = {t["name"]: t for t in allowlist["tools"]}

def route_skill(skill_name: str):
    if skill_name not in APPROVED_SKILLS:
        raise RuntimeError(f"Skill '{skill_name}' is not approved for runtime use")
    ...

def call_tool(tool_name: str):
    tool = APPROVED_TOOLS.get(tool_name)
    if not tool:
        raise RuntimeError(f"Tool '{tool_name}' is not in the runtime allowlist")
    return tool["endpoint"]
```

### Regeneration

```bash
# Local
python scripts/runtime_allowlist.py

# CI (automatic on every push to master/main that modifies a registry file)
# See .github/workflows/skill-ci.yml — Stage 3
```

### Status enforcement

| Status | Appears in allowlist? | Runtime behaviour |
|--------|----------------------|-------------------|
| `approved` | Yes | Fully callable |
| `restricted` | Yes | Callable with additional access checks |
| `draft` | No | Invisible to runtime |
| `submitted` | No | Invisible to runtime |
| `needs_revision` | No | Invisible to runtime |
| `deprecated` | No | Runtime should reject calls and log a warning |
| `retired` | No | Runtime must raise an error |
